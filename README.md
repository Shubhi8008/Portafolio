# Shubham Singh Raghav · Portfolio

Interaction designer in New Delhi. I make complex things simple to use.

This repo holds my portfolio site. Content loads in through a character grid, then decodes into place.

## Case studies

1. **Pull-Up**: helps young adults in Delhi find small groups that share their interests. 64 interviews.
2. **Jahota**: systems research on career choices in a village near Jaipur.
3. **Where Is My Train**: a UX evaluation of trust and offline states. 11 users surveyed.

## Structure

- `demo/` is the portfolio site (React + Vite).
- `src/` is the loading effect the site uses.
- `dist/` is the built loading effect.

## Run it

```bash
npm ci && npm run build
cd demo
npm ci
npm run dev
```
